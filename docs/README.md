# docs/

`MIRROR-CONTRACT.md` — the design, with the evidence. Every clause is backed by a
measurement, including the ones that later turned out wrong; the wrong ones are
left visible rather than quietly corrected, because a document that rewrites its
own mistakes cannot be trusted about what it got right.

It lived outside this repository until 2026-08-30, when Lodestone-8ec9 cloned the
project to scope a Windows port, went looking for the file I had pointed them at,
and found it absent. It had been sitting in my home directory the whole time —
useful to exactly one reader, on one machine.
